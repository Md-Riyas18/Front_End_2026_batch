JavaScript (JS) is a lightweight, interpreted or just-in-time compiled programming language used to make web pages interactive and dynamic

• Front-End Development: Building interactive user interfaces using libraries and frameworks like React, Vue.js, or Angular.

• Back-End Development: Writing server-side logic, APIs, and real-time apps with Node.js.

• Mobile & Desktop Apps: Creating cross-platform mobile apps (React Native) and desktop applications (Electron).

• Arrow Functions: A shorter syntax for writing function expressions using () => {} which automatically binds the surrounding this context.

• Destructuring: A streamlined way to extract values from arrays or properties from objects into distinct variables (e.g., const { name, age } = user;).

• Spread and Rest Operators: The ... syntax used to expand arrays/objects or combine multiple function arguments into an array.

• Template Literals: String interpolation using backticks ` and ${variable} instead of string concatenation with plus signs.
