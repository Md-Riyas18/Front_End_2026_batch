What is an HTML ?

Define HTML ?

  • HTML stands for Hyper Text Markup Language.
  • It is a Markup Language used to Structure a Information and Layout to Make a Web-page.
  • HTML used to Structure your Un-structured Data.

HYPER----> Hyper Means Connection or Linking One Web-page / Document to Another.

TEXT----> Text Means the Connect Display On Webpage.

MARKUP----> Markup Means Using HTML Tags to Define the Structure and Meaning of Content.

LANGUAGE----> Language Means System With Rule and Syntax Used to Communicate Information Between Human and System .


What is an Tags ?

Define Tags ?

Tags is an Pre-Defined Keyword Enclosed With Angular Bracket <>

Example ;

<p>

There are 2 types of tags ;

  • Closing Tags
  • Self-Closing Tags

Closing Tag :

Closing Tag are used to making content.

Closing Tag Examples ;

<p>This is a paragraph</p>

<h2>This is a heading</h2>

<div>This is a division</div>

Self-Closing Tag :

Self closing tags are making direct content

Self-Closing Tag :

<br>

<hr>

<img src="photo.jpg" alt="Photo">

<input type="text">

What is an Element

Define Element ?

  • Element is used to making a browser structure.
  • One element contains one opening tag <p>, one closing tag </p>, inbetween have content(This is HTML) this are called element.

Example ;

<h1>This is HTML</h1>

  • <h1>----> This is opening tag.
  • This is HTML----> This is content
  • </h1>----> This is closing tag

There are 4 types of elements ;

  • Root Element
  • Container Element
  • Parent Element
  • Child Element

Root Element :

Root Element means only HTML.

Example ;

<HTML>,</HTML>

Container Element :

Container Element menas Head and Body.

Example ;

<head></head> , <body>,</body>

Parent Element :

Parent Element means holding child element

2 types of Parent element ;

  1. Semantic Element
  2. Non-Semantic Element

Example ;

<p>This is HTMl</p>

</HTML>
