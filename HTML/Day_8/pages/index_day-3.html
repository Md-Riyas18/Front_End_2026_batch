Attributes:

What is an Attributes ?

  • Attributes provide addtion information of tag.
  • It's give addition behaviour,desing and function to add the tag and element.
  • Attributes are written inside opening tag
  • Attributes are help to dynamic webpage creation

Syntax :

<tag attribute ="value">content</tag>

Example ;

<a href="../pages/index_day-2">Day-2</a>

There are 2-types of Attributes ;

  1. Global Attributes
  2. Local Attributes

1.Global Attribute :

Global attribute can be used on most of all HTML element.

Example ;

class

id

style

hidden

dir

2.Local Attribute :

Local attribute are the attribute that are mainly used with specified HTML element. They are not normallly appplicable to every HTML element.

Example ;

<a> = href

<img> = src

<input> = type


Now we seen 2-Type of Tag ;

1.Anchor Tag :

It's is used to create a link from one webpage to another webpage,website,file,email or location on same webpage . Using of anchor tag we can navigate one website or webpage to another.

Syntax :

<a href="value">content</a>
