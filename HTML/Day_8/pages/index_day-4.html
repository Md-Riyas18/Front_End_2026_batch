We Seen HTML Basic List, Div, Table, Form :

1.HTML List :

Define List :

HTML lists are used to display a collection of related items.

  • Unordered List
  • Ordered List
  • Description List

1.Unordered List :

An unordered list displays items with bullets.

Tags :

<ul>----> Unordered List

<li>----> Line Item

Example :

<ul>

<li>HTML</li>

<li>CSS</li>

<li>JS</li>

</ul>

Output :

  • HTML
  • CSS
  • Js


2.Ordered List :

An Ordered list displays items with numbers.

Tags :

<ol>----> Ordered List

Example :

<ol>

<li>HTML</li>

<li>CSS</li>

<li>JS</li>

</ol>

Output :

  1. HTML
  2. CSS
  3. Js


3.Description List :

A description list is used for terms and their descriptions.

Tags :

<dl>----> Description List

<dt>----> Description Term

<dd>----> Description Definition

Example :

<dl>

<dt>HTML</dt>

<dd>Used to structure webpages.</dd>

<dt>CSS</dt>

<dd>Used to style webpages.</dd>

<dt>JavaScript</dt>

<dd>Used to add functionality to webpages.</dd>

</dl>

Output :

HTML :
Used to structure webpages.
CSS :
Used to style webpages.
JavaScript :
Used to add functionality to webpages.


2.Div Element :

Definition of Div :

<div> is a generic block-level container. It is mainly used to group and organize HTML elements.

Example ;

<div>

<h1>Student Profile</h1>

<p>Name: Arun</p>

<p>Course: Full Stack Development</p>

</div>

Output :

Student Profile

Name: Arun

Course: Full Stack Development


3.Table Element :

Definition of Table :

Tables are used to display data in rows and columns.

Syntax :

<table border="1" cellspacing="5" cellpadding="10">

Border----> Border Line

Cellspacing----> Space between cells

Cellpadding----> Space inside cell

<thead>----> Table Head

<tbody>----> Table Body

<tr>----> Table Row

<td>----> Table Data

Example ;

<table border="1">

<thead>

<th>Name</th>

<th>Course</th>

<th>Age</th>

</thead>

<tbody>

<tr>

<td>Arun</td>

<td>Full Stack</td>

<td>22</td>

</tr>

<tr>

<td>Priya</td>

<td>Java</td>

<td>23</td>

</tr>

</tbody>

</table>

Output :

Name Course Age
Arun Full Stack 22
Priya Java 23

4.Form :

Definition of form :

Forms collect user input.

Example :

  • Login
  • Registration
  • Contact Form
  • Search
  • Feedback Form
  • Job Appliation

i).Form :

Define the form.

Syntax :

<form></form>

ii).Label :

Provide label for a input.

Syntax :

<label>name:</label>

iii).Input :

Used to collect different types of user input.

Syntax :

<input type:"text">

iv).Select :

Creat a drowdown.

Syntax :

<select>

<option>chennai</option>

<option>trichy</option>

</select>

v).Textarea :

Used to multi-line text

Syntax :

<textarea row="s" cols="30"></textarea>
