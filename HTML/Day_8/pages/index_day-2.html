Day-2 of HTML

Types of Element ;

  1. Block-Level Element
  2. In-line Element
  3. Symantic Element
  4. Non-Symantic Element

1.Block-Level Element :

Block-level element are starting with a new line and it take entire line width and its is used to make building block of an webpage.

Example ;

<p>This is HTMl</p>

<h1>This is CSS</h1>

<div>This is JS</div>


Output ;

This is HTMl

This is CSS

This is JS


Some Example of tags ;

<h1>

<p>

<header>

<title>

<section>

<main>

<footer>


2.In-line Element :

In-line Element are not starting with new line it is starting inside a line and it's only take content width . In-line tag are called helper tag.

Example ;

<p><strong>This is HTMl</strong></p>

<h1><i>This is CSS</i></h1>

<div><span>This is JS</span></div>


Output ;

This is HTMl

This is CSS

This is JS


Some Example of tags ;

<i>

<strong>

<em>

<sub>

<sup>

<b>

<u>


3.Semantic Element :

Semantic tag are meaningful tag. This tag is help to understand clearly of your webside to developer and browser. It as no behaviour but it has meaning.

Example ;

<header>

<h1>This is HTMl</h1>

<p>This is CSS</p>

<p>This is JS</p>

</header>


Output ;

This is HTMl

This is CSS

This is JS


Some Example of tags ;

<header>

<main>

<section>

<footer>

<summary>

<article>

<figure>


4.Non-Semantic Element :

Non-Semantic tag are not meaningful tag. This tag is only used for grouping.

Example ;

<div>

<h1><span>This is <strong>HTMl<strong></span></h1>

<p>This is CSS</p>

<p>This is JS</p>

</div>


Output ;

This is HTMl

This is CSS

This is JS


Some Example of tags ;

<div>

<span>


<section>

<div>

<h1><span>This is <strong>HTMl<strong></span></h1>

<p><strong>This is CSS><strong></p>

<p>This is JS</p>

</div>

</section>
