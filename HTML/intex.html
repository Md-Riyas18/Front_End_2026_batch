WHY DID WE BUILD THE WEBSIDE? We built the website to solve problems that happened in past real-world incidents. We studied previous incidents, identified their weaknesses, and designed our website with security features to prevent or reduce similar incidents in the future. EVALUATION OF THE WEBSIDE? 1. Introduction to the Web; Time: 1990s Creation of the World Wide Web i) Websites were mainly used for sharing information ii) Simple HTML pages with text and hyperlinks iii) Mostly static content 2. Static Websites; Time: Early 1990s–2000 Basic HTML and simple CSS i) No user accounts or complex interaction ii) Used by organizations to provide information Example: Company profile or personal webpage 3. Dynamic Websites; Time: 2000–2005 Websites started using databases and server-side programming i) Users could log in, submit forms, and interact with websites ii) Technologies such as PHP, ASP, and MySQL became popular iii) Major change: Static pages → Interactive pages 4. Web 2.0 – Interactive Websites; Time: 2005–2010 Users became content creators i) Social media, blogs, forums, and online communities grew ii) AJAX and JavaScript improved website interaction Examples: Facebook, YouTube, Wikipedia 5. Rise of E-Commerce and Online Services; Time: 2000s–2010s i) Websites became platforms for shopping, banking, booking, and payments ii) Personal and financial information was stored online iii) Major concern: Data security and online fraud 6. Security Evolution; Problem: Password theft, SQL injection, XSS, phishing, and data breaches Websites introduced: i) HTTPS/SSL ii) Strong password policies iii) Authentication iv) Authorization v) Input validation vi) Firewalls and security monitoring 7. Mobile-Friendly Websites; Time: 2010s i) Rapid growth of smartphones ii)Websites needed to work on different screen sizes iii)Responsive web design became important iv)Mobile-first development became common 8. Cloud-Based Websites; Time: 2010s–Present i)Websites moved toward cloud infrastructure ii)Better scalability and availability iii)Services could handle millions of users iv)Cloud storage, APIs, and distributed systems became common 9. Modern Web Applications; Time: 2015–Present i)Websites became more like applications ii)Technologies such as React, Angular, Vue, Node.js, and APIs iii)Single-page applications became popular iv)Faster and more interactive user experiences v)10. Advanced Authentication and Privacy vi)Password-only security became insufficient Introduction of: i)Two-factor authentication ii)Multi-factor authentication iii)Biometrics iv)OAuth v)Role-based access control vi)Stronger privacy and data-protection practices 11. AI-Powered Websites; Time: 2020–Present AI is used for: i)Personalization ii)Chatbots iii)Fraud detection iv)Recommendation systems v)Behaviour analysis vi)Automated security monitoring 12. Future of Websites; i)AI-driven applications ii)Stronger biometric authentication iii)Zero-trust security iv)Real-time threat detection v)More automation vi)Greater focus on privacy and cybersecurity 13. Overall Evolution; Static Information ↓ Dynamic Websites ↓ Interactive Web 2.0 ↓ E-Commerce & Online Services ↓ Mobile & Cloud Websites ↓ Modern Web Applications ↓ Secure & AI-Powered Websites ↓ Intelligent and Highly Secure Future Web
